# Portfolio React Port

This workspace has been scaffolded to use a minimal React + Vite setup. The original static assets remain in `elements/` and `files/` and are served as static files.

Quick start:

1. Install dependencies

```
npm install
```

2. Run dev server

```
npm run dev
```

Notes:
- The app entry is `index.html` and `src/main.jsx`.
- Global styles are imported from the existing `global.css`.
